# 제출 구성 안내

이 GitHub 제출 폴더는 코드 확인용으로 구성하였다.

## 포함된 코드

```text
src/
- TF-IDF + Logistic Regression 학습/예측 코드
- KLUE-BERT 학습/예측 코드
- KLUE-BERT 3중 처리 최종 모델 학습 코드

android_sms_classifier/
- Android Studio 앱 코드
- SMS/알림 감지
- 재난 키워드 필터링
- 중복 알림 제거
- Hugging Face 서버 호출

huggingface_space/
- Hugging Face Spaces 배포용 FastAPI 서버 코드
```

## 최종 모델 기준

최종 사용 모델은 `KLUE-BERT 3중 처리 모델`이다.

최종 불균형 처리:

```text
Random Oversampling
EDA 텍스트 증강
Weighted Loss
```

최종 예측 서버는 Hugging Face Spaces에 배포한 KLUE-BERT 3중 처리 모델을 사용한다.

```text
https://vbcbxb-disaster-classifier.hf.space/predict
```

## 포함하지 않는 파일

GitHub에는 아래 파일을 포함하지 않는다.

```text
data/
outputs/
best_model/
checkpoints/
*.zip
*.joblib
*.safetensors
*.bin
```

이 파일들은 용량이 크거나 실행 결과물이므로 별도 제출 자료에 포함한다.
